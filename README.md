# HackerRank Tasks

A repository for solving HackerRank coding challenges in multiple programming languages.

## Current Status

- **Python**: In progress - solving various challenges

## Project Structure

```
Python/          # Python solution files
├── company_logo.py
└── ...
```

## Getting Started

Each solution file contains:
- A link to the HackerRank problem
- Standard library imports
- Implementation of the solution

### Running a Solution

```bash
python3 Python/challenge_name.py
```

## Development Workflow

1. Create a new branch for each challenge (e.g., `company_logo_dp`)
2. Implement the solution in the appropriate language folder
3. Test with sample inputs from the problem statement
4. Commit changes with descriptive messages
5. Push your branch and create a pull request for review
6. Address any feedback and merge when approved

For detailed AI agent instructions, see [`.github/copilot-instructions.md`](.github/copilot-instructions.md).
